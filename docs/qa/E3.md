# E3: "Ask GetPaid" help assistant (solo build and test, 12 Nov 2026)

Branch `feat/E3-help-assistant`. Decisions are in `docs/DECISIONS.md` ("E3 choices").

## What was built

- A fifth AI task, `help` (migration `035_ai_help_task.sql`), with its own model field in Settings > AI; empty uses the main model, and with no model it says "Set a model in Settings > AI".
- `scripts/build-help-sections.ts` (`npm run help:sections`) cuts `docs/help/manual.md` into 61 sections by heading and writes `apps/web/src/content/help-sections.json`.
- Plain BM25 keyword retrieval (`lib/help-search.ts`): the best 5 sections go to the model.
- `prompts/help-assistant.md`, `prompts/schemas/help-answer.schema.json` (`answer` at most 1,200 characters, `sources`, `links`); links filtered against an allowlist of real routes, sources against what was sent.
- `POST /api/help`, the Help button (question-mark icon) in every dashboard header and its side panel (three suggestions, answer, "From the manual: ...", links, "Download the manual (PDF)").
- The calendar assistant sends how-to questions to the same task and shows the answer the same way.
- Manual sections for E1 and E2 and for Ask GetPaid itself, the sections file regenerated.
