# QA: A3 export

Solo mode, 9 Nov 2026. Branch `feat/A3-export`.

## Checked

- `npm run check`: green (101 files, 2487 tests passed, 1 skipped).
- `npm run test:e2e`: 136 passed (the whole suite, run with the final code).
- Diff reviewed against `docs/PHASE2-PLAN.md` sections 2 and 11 and the A3 text in 7.A3.
- Test A-S2 (`tests/phase2/calendar-export.test.ts`): a title containing `\r\nATTENDEE:mailto:x@evil.test` becomes one escaped `SUMMARY` line and the file has no `ATTENDEE` line; every physical line is at most 75 octets, continuation lines start with one space, a title with accents, Japanese and an emoji unfolds back to the original (no character split); the export holds only the owner's items (another user's entry, client name and id are absent); notes appear only with `notes=1`; an imported item passed to `toIcs` is dropped; a range over 400 days answers 400.
- **Run in a real browser** with a throwaway Playwright spec on the E2E server (not committed, because of the no-UI-tests policy): the Export card's "Everything" plus "Include notes" gives the link `/api/calendar/export.ics?notes=1`, pressing it downloads `getpaid-calendar.ics`; the file holds the new timed entry with `DTSTART:20261210T093000Z` (15:00 in Asia/Kolkata), `SUMMARY:Kick-off call\, with\; commas`, its notes, and a `URL:` back to the app; the entry's page shows working Google and Outlook links with the title, UTC times and notes encoded.

- **A flaky test, now identified:** a `npm run check` that ran while the E2E suite was running failed with `tests/invoice-pdf.test.ts > renders a built-in template to a PDF` timing out at 60 s (it starts Chromium and was starved of CPU). Rerun alone, the whole check passes (2487 tests). This is very likely the unidentified failure noted in `docs/qa/A2.md` too, which also happened while another heavy job ran. Don't run `check` and `test:e2e` at the same time.

## Rules checked

- The route runs as the signed-in user; no `service_role`.
- Imported events are filtered out in `toIcs` itself, so no caller can export them.
- The log line has only the event name and whether notes were included. No titles.
- The `.ics` has no emails, pay links or amounts beyond what an item's title already says (invoice-due titles carry the amount, as the plan's feed rule says).
- Response is `text/calendar; charset=utf-8`, an attachment, `no-store`.
- No new dependency.
