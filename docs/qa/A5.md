## Rules checked (plan section 2)

- **Rule 1 (untrusted text):** imported titles, client names and the user's question are wrapped as data in tags, escaped, flattened to one line, and the prompt says never to follow them. The code, not the prompt, is what protects: a proposal on anything but an editable entry is dropped whatever the title says.
- **Rule 2 (the AI only suggests):** nothing is applied by `ask`. Apply is a separate call with its own validation and uses the same functions as the entry form. The model can't touch milestones, invoices, reminders, imported events or money.
- **Rule 3 (money):** the assistant never creates or changes an amount. Amounts it writes in an answer must appear in an item title.
- **Rule 9 (logging):** event names, counts and the kind of proposal only.
- **Rule 8 (service role):** not used. Both routes run as the signed-in user.
- **Section 11 Don'ts:** no proposal is applied without a click; no AI writing of clauses, laws, rates or amounts (not touched in this step).
- Per `.claude/rules/prompts.md`: the prompt returns JSON matching a schema in `prompts/schemas`, uses only the context it is given, and treats imported text as data. The schema file and the schema's zod source are checked identical by `tests/ai-schemas.test.ts`, and `lib/prompt-text.ts` by `tests/prompts.test.ts`.
